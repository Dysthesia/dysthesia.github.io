# Manim video destination

The starter does not contain pre-rendered MP4 files. The live browser illustrations
work immediately and are clearly identified as browser illustrations, not Manim.

Run `python python/render_lessons.py` from the project root after installing Manim.
The script will place these files here:

- `discriminant.mp4`
- `completing-square.mp4`
- `newton.mp4`

Select **Manim video** on the page to play them. Missing files show a helpful
empty state. After adding videos, click **Retry video** or reload the page.
The adjacent **Read this lesson** panel is a text alternative to both modes.
