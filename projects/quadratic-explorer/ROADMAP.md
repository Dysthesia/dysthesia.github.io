# Improvements for you to build

The core features are implemented. These are deliberate extension opportunities,
not hidden requirements to make the existing calculator work.

## Small first wins

- [ ] Add a “downward parabola” preset, such as −x² + 4x − 3.
- [ ] Add a y-intercept marker and toggle to the graph.
- [ ] Display vertex form alongside the standard form.
- [ ] Customize the colors and project introduction.
- [ ] Add a test for a quadratic you solved in your own notes.

## Build your JavaScript and numerical-method skills

- [ ] Add the secant method with two starting values and a zero-denominator guard.
- [ ] Add panning and a user-controlled graph window.
- [ ] Save coefficients in the URL so an example can be shared.
- [ ] Add a slider that traces x and f(x) using only the keyboard.
- [ ] Draw an error-versus-iteration chart for Newton and bisection.
- [ ] Explain a rational factor pair by enumerating candidates rather than using
      the discriminant to identify rational roots.
- [ ] Add automated browser tests for form validation, keyboard input, and mobile layout.

## Build your Python and mathematics skills

- [ ] Render the included Manim scenes and add the resulting MP4s to your site.
- [ ] Replace the text-only completing-square scene with a geometric area model.
- [ ] Add a scene showing how a, b, and c affect the parabola.
- [ ] Implement the same solver in Python and cross-check it against JavaScript.
- [ ] Use SymPy to produce exact fractions and simplified radicals at every step.
- [ ] Make scene examples configurable from a JSON file and regenerate the videos.

## Later: complex roots

- [ ] Add complex-root calculation when Δ < 0.
- [ ] Display conjugate pairs in the complex plane.
- [ ] Explain why complex roots are not x-intercepts of the real parabola.
- [ ] Add tests for signs, conjugacy, Vieta's formulas, and a negative leading coefficient.

Choose one improvement at a time. Define its expected behavior, implement it,
test it, then describe what you learned in the README.
